# Portal do Japão — Landing Page

Landing page cinematográfica criada em Next.js, TypeScript, GSAP e Lenis.

## Rodar localmente

```bash
npm install
npm run dev
```

Abra `http://localhost:3000`.

## Conteúdo

- Hero fullscreen com pôr do sol e Torii em SVG
- Seção Sobre com café regional
- Cards de experiências
- Galeria interativa com transição e parallax
- Localização e CTA para WhatsApp
- Layout responsivo para celular e desktop
